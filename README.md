# Бот для отображения изображений с matrix сервера
## В связи с введением новшеств в matrix на новой версии увидеть изображение через ссылку в "Поделиться" не получится, для этого создан этот бот
Бот запускается с помощью config.ini, после чего ожидает запроса на эндпоинта
https:/<имя сервера>/image/<!room_id>/<$event_id>
в ссылке должны быть указаны два параметра:
room_id - номер комнаты, где находится изображение - 
event_id - номер события с изображением - 
после чего бот получает mxc-ссылку на это изображение, загружает и выводит в браузер
